# MTU: Multifunction Tree Unit

MTU accelerates binary-tree workloads in zero-knowledge proofs using a hybrid traversal strategy. This directory contains the DFS processing-element scheduler, its Verilog testbench, and a C software model.

## Reference

Jianqiao Mo, Alhad Daftardar, Joey Ah-Kiow, Kaiyue Guo, Benedikt Bünz, Siddharth Garg, and Brandon Reagen. 2025. **MTU: The Multifunction Tree Unit for Accelerating Zero-Knowledge Proofs.** In *Proceedings of the 14th International Workshop on Hardware and Architectural Support for Security and Privacy (HASP ’25)*, 19–27. DOI: [10.1145/3768725.3768737](https://doi.org/10.1145/3768725.3768737). [Open-access preprint](https://arxiv.org/abs/2507.16793).
